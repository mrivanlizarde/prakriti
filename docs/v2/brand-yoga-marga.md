# Yoga Marga brand conventions for thumbnails (read from yogamarga.school, Mon 12 Oct 2026)

Measured from the live site's HTML and CSS (frequency of use in parentheses). The blues #188bf6 and #3b82f6 are
GoHighLevel's default UI colors, not the brand, and are excluded.

| Role | Value |
|---|---|
| Headline type | **Alegreya** (serif; most-used family, 31 uses), with **Alegreya SC** for small caps |
| Supporting type | **Alegreya Sans** (18 uses), Alegreya Sans SC |
| Accent | **#DC6B09** saffron orange (8) |
| Warm secondary | **#975131** earth brown (7) |
| Highlight | **#F3CF8A** soft gold (2) |
| Neutrals | #000000, #FFFFFF, #111827 near-black, #F5F5F5 |

Alegreya and Alegreya Sans are SIL Open Font License: safe to embed and to burn into thumbnails and videos
(unlike SF Pro). Bundle the .ttf files from Google Fonts in the app; render the Sanskrit diacritics (ā, ṛ, ṣ)
in a test and look at them.
